# Content Strategy — German & Russian

## Account architecture

**Provisional model:** two related Instagram profiles (DE and RU) with one unified editorial operation. Final account names and audience markets remain open.

Each story gets an immutable content ID (e.g. HS-001) and a common research record. Publish separately adapted versions:

| Layer | Shared | Localized |
|---|---|---|
| Research and verified collection facts | Yes | Add culturally useful context |
| Visual direction and permitted assets | Usually | Alternate crop or cover if needed |
| Main idea and content ID | Yes | Different hook allowed |
| Caption | No | Native DE / native RU |
| Hashtags and search keywords | No | Audience-appropriate |
| Question / CTA | No | Natural wording and tone |
| Publish schedule | No | Test per account |
| Metrics | No | Track independently |

Never automatically post duplicated literal translations without editorial review.

## Editorial audiences

People interested in runway fashion, beautiful clothing, craftsmanship, accessories and thoughtful styling. Avoid claiming an exact age, income or buyer segment before testing.

## First editorial campaign

**Target:** 30 distinct concepts across approximately 6–8 weeks (working proposal), choosing the first 10 pilots before production.

Mix photo posts, carousel narratives, close-up details and short video formats when rights and source materials support them.

## Post specification

- Story ID and title
- Country / city / fashion house / exact season
- Verified fact and source link
- One identifiable Helena observation
- Visual shot list or image references and licensing status
- DE hook, caption, question, SEO terms, up to 5 meaningful hashtags and alt text
- RU hook, caption, question, SEO terms, up to 5 meaningful hashtags and alt text
- Format, publishing status, language-specific performance

## Discovery strategy

Write captions for humans first, with relevant descriptive words. Use accurate designer/collection labels. Invite useful discussion; no automated comments, inflated follower counts, keyword stuffing or claims of guaranteed algorithm boosts.

Assess saves, shares, comments quality, profile visits, follows and retention by content pillar. Small tests should guide later choices.
